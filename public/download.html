How to install by operating system
🤖 AndroidPress Download APK → allow “unknown sources” → Install. Beta APK 1.0, Android 6.0+, ±65 KB.
📱 Huawei (HarmonyOS)Same as Android — download the APK directly and install it. Or Chrome → ⋮ → Install app.
💻 ChromeOSMost Chromebooks support APKs (Google Play). If yours doesn’t, use the Install app button (PWA).
🪟 WindowsEdge/Chrome → the Install icon in the address bar — T Chat becomes a full desktop app. Dark mode, notifications, works offline.
🐧 LinuxChrome/Chromium/Firefox ⚠ (Chromium: ⋮ → Apps → Install this site as an app). Becomes a desktop app like a native one.
🍎 macOSSafari/Chrome → File → Add to Dock (Chrome: ⋮ → Apps → Install). Looks and feels like a regular app.
📱 iOS / iPadOSOpen in Safari → share (□↑ icon) → Add to Home Screen. Runs like a normal app, no App Store needed.
🌐 Other OST Chat is a web app (PWA) — any modern browser can use and install it. Android-like (Fire OS, Ubuntu Touch…) → APK directly.
