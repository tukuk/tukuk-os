Mengesan peranti anda…

Buka pautan ini di peranti lain (contoh: telefon) untuk pasang di sana.

Cara pasang ikut sistem pengoperasian
🤖 AndroidTekan Download APK → benarkan “sumber tidak diketahui” → Pasang. APK beta 1.0, Android 6.0+, ±65 KB.
📱 Huawei (HarmonyOS)Sama seperti Android — muat turun APK terus dan pasang. Atau Chrome → ⋮ → Pasang aplikasi.
💻 ChromeOSKebanyakan Chromebook menyokong APK (Google Play). Jika tiada, guna butang Pasang aplikasi (PWA).
🪟 WindowsEdge/Chrome → ikon Pasang di bar alamat — T Chat jadi aplikasi desktop penuh. Mod gelap, notifikasi, work offline.
🐧 LinuxChrome/Chromium/Firefox ⚠ (Chromium: ⋮ → Aplikasi → Pasang aplikasi ini). Jadi aplikasi desktop seperti native.
🍎 macOSSafari/Chrome → Fail → Tambah ke Dock (Chrome: ⋮ → Aplikasi → Pasang). Nampak seperti aplikasi biasa.
📱 iOS / iPadOSBuka di Safari → kongsi (ikon □↑) → Add to Home Screen. Berjalan seperti aplikasi, tanpa App Store.
🌐 OS lainT Chat ialah aplikasi web (PWA) — apa-apa pelayar moden boleh gunakan dan pasang. Android-like (Fire OS, Ubuntu Touch…) → APK terus.
