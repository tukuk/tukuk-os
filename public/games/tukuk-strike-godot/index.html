Read first — this build is heavy.
  • It downloads about 476 MB of assets plus 38 MB of engine, so it needs a broadband connection. Do not open it on metered, roaming or capped mobile data.
  • Needs a modern browser with WebGL2. Desktop is recommended; the first frame can take a minute while the engine unpacks, and weak phones may stall or refuse to boot.
  • It opens top-level in its own tab (play.tukuk.org), not inside this page — the Godot build needs a browsing context of its own, so it cannot be embedded here without breaking the main site.
  • If the tab stays blank, the build may not be published on the server yet — try the light version below.
