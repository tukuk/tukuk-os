📢 Google & Microsoft Ads Settings ("Rumah Iklan")

Configure Google AdSense and Microsoft Advertising (Bing Ads) banners safely.

Google AdSense

Microsoft Advertising (Bing Ads / Monetize)

Alternative to "Auto ads" from Microsoft. Paste the single script URL given by the Microsoft dashboard (monetize/usm) here. When Enable Microsoft Advertising is on, the loader is injected into the head of every ad-safe page. Empty = no USM.

Full Microsoft Ads Snippets (HTML/JS)

Microsoft (monetizenow) usually gives a full HTML/JS snippet per unit. Paste it here. The renderer injects it as-is when Microsoft Ads is enabled. Empty = nothing shown.

Microsoft Clarity (Analitik usage)

Get the ID from clarity.microsoft.com. It only loads when enabled (see /api/public/settings).

Google Tag (Tag Manager)

The single Google tag for the site. Configure Google Analytics 4 (and any Google Ads/conversion tags) inside the container at tagmanager.google.com — do not also paste a separate gtag.js, or pageviews get double-counted. Loads on content pages only (not the tag-free legal pages). It only loads when enabled.

⚡ Fast Ad Network (Adsterra / PropellerAds / etc)

⚠️ When ON, this network replaces AdSense on every page (never mixed — avoids an AdSense BAN). Turn this toggle off as soon as your AdSense starts serving ads. Get the URL from the dashboard (Adsterra/PropellerAds → Zone → Universal/Smart Code → copy src).

🛒 Affiliate Products (Recommendations)

Shown on /rekomendasi. Format: JSON array. Replace url with your real affiliate links (Shopee/Amazon/Hostinger/NordVPN etc). Empty = use the default list.

Available fields: name, blurb, price, url, cta. Outbound links automatically get rel="sponsored nofollow" (Google-compliant).
