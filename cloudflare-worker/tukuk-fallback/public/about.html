Tukuk-OS is a web search engine for the tukuk.org domain. It is built to search public web pages, with priority on answer quality and source transparency.

How it works

LayerRole
MeilisearchStores and scores the inverted index. Runs on port 7700.
API serverNode.js + Express, port 8000. Serves search, the crawler, and the API.
CrawlerCustom code. Respects robots.txt, avoids internal addresses.
BrainA small language model via Ollama. Builds answers from the sources it finds.

Search features

  • Word highlighting and summaries with context
  • Automatic typo tolerance
  • Malay & English synonyms (cari, carian, pencarian, geledah)
  • Facets: site, language, content type
  • Filters by time, word count, and domain
  • Autocomplete suggestions

Privacy and transparency

Every answer from the brain includes a list of source URLs. If no sources are sufficient, the system behaves honestly and says it does not know — it does not invent facts.
